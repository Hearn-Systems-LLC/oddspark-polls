## Successes and strengths

1. **More-automated delivery process worked.** Spec → implement → adversarial review → full gate → explicit-path commit improved consistency. Project Lead called this out explicitly: keep and refine the loop.
2. **1,001-Vote capacity contract.** Catching Worker memory vs unbounded XLSX before shipping was the epic’s best technical product decision. Fail closed with exact `409` and CSV fallback.
3. **Privacy-first, format-neutral export.** Authorize before private reads; positive allowlist; one canonical dataset for CSV and XLSX so Ranked can plug a projector without forking exporters.
4. **Adversarial review + machine gate caught false-complete (Story 4.2).** Incomplete graph (orphaned components, unwired routes, tests asserting unemitted payloads) was reset and re-derived rather than rubber-stamped.
5. **Epic 3 retrospective prep commitments honored.** Story context for 4.1, multi-factor delivery gate, and 1280px light / 375px dark browser proof for comments and export surfaces.

---

## Challenges and growth areas

1. **New process friction.** Branch-mismatch auto-dev blocks, multi-spec thrash on 4.4, and re-derives felt rough. Project Lead: flow will smooth as the team adjusts — treat as calibration, not failure.
2. **Definition-of-done gaps.** Story 4.2 first pass marked complete while the production graph was disconnected. Need full-diff / orphan / tracker-consistency as non-negotiable exits.
3. **Platform product contracts decided mid-story.** Unbounded sync XLSX vs workerd limits required four spec generations. Capacity bounds should be first-class in the initial plan for Worker-bound features.
4. **Tracker vs mainline lag.** Sprint-status reported Epic 4 / 4.4 `done` while `origin/main` still lacked the final XLSX implementation. Status must not lead remote truth.
5. **Follow-up review damping without closure.** DW-50 (4.1) and DW-51 (4.3) preserve “follow-up recommended” after damping cap; need a scheduled pass or explicit residual acceptance.
6. **Known Vote recovery integrity edges** (flash-sign post-commit; timed form restore / fresh submission ID when Session and IP checks are both off) sit beside the extended Vote path and remain deferred.

---

## Key insights and learnings

1. Automation amplifies discipline: wrong branch and incomplete graphs fail loudly — jarring but correct.
2. Worker-bound features need **capacity sentinels in the plan**, not only in review (pattern: 1,001 Vote bound).
3. “Done” must mean **spec + production graph + full gate + merge path**, not any single signal.
4. Process will smooth **if adjustments are encoded**; hope alone is not a plan.
5. Export projection port is now load-bearing for Epic 5 Ranked rows — do not invent a second export path.
